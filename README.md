# suzu の Splatoon レイアウト・スクリプト置き場

FF14 の Dalamud プラグイン **Splatoon** 用に作ったレイアウトとスクリプトを公開しています。

- 対応クライアント: **日本語版**（他言語クライアントではトリガーが動かない場合があります）
- ブログ：https://ameblo.jp/suzuffxiv/entry-12982828867.html

## はじめての方へ
取り込み方は **[取り込み方ガイド](docs/取り込み方.md)** を見てください。
レイアウトはコピーボタン1回、スクリプトは「Copy raw file」ボタン1回でコピーできます。
