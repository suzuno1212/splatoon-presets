## スクリプト

### レプリケーション1回目 闇・炎誘導ガイド（近接・タンク）
- ファイル: [M12S_P2_Replication1_DarkBait.cs](M12S_P2_Replication1_DarkBait.cs) → 開いて右上の「Copy raw file」
- 何をするか: 2回目の分身移動で**最外周（斜め）に来た闇分身**を北とみなし、近接・タンクの**闇誘導位置**と**炎誘導位置**を表示します。自分の担当（闇耐性低下IIあり=炎、なし=闇）の位置にはガイド線を引きます。
- 対象: タンク・近接DPS（ジョブから自動判定。ヒーラー・遠隔は表示なし）
- 設定項目:
  - ロール（自動 / タンク / 近接）
  - 炎誘導位置の表示、担当の位置へのガイド線、相方の位置の表示
  - 色
- 攻略法の前提: game8 位置固定式。最外周の闇分身を北として DPS が左・タンクが右

### アルカディアンドリーム 自動マーカー＋チャット通知
- ファイル: [M12S_P2_IdyllicDream_AutoMarker.cs](M12S_P2_IdyllicDream_AutoMarker.cs) → 開いて右上の「Copy raw file」
- 攻略法の前提: game8 / ぬけまる式（入れ替え 1↔B・4↔C）
- 何をするか:
  1. 模倣細胞から自分についた線の方角で、担当のマーカーを**自分に自動で付けます**
  2. 模倣細胞が最初に出た形（十字 / X字）をパーティチャットに出します（「A-D頭割りから」「1-4頭割りから」）
  3. 空間裂断の後、安置の島と向きをパーティチャットに出します（例「東島のタテが安置」）
  4. 島の扇が発動した瞬間に、最後の扇の安置をパーティチャットに出します（「最後はタテ安置」「最後は横安置」）

| 線の方角 | 入れ替え後の担当 | マーカー |
|---|---|---|
| 北(A) | A | 攻撃4 |
| 北東(2) | 2 | 攻撃1 |
| 東(B) | 1 | 禁止2 |
| 南東(3) | 3 | 攻撃2 |
| 南(C) | 4 | 禁止1 |
| 南西(4) | C | 鎖1 |
| 西(D) | D | 鎖2 |
| 北西(1) | B | 攻撃3 |

- 設定項目: マーカーを付けるまでの秒数、外すまでの秒数、位置ごとのマーカー、各チャットの有無・秒数・文面
- 注意:
  - マーカーは**パーティ全員に見えます**。全員が同じ攻略法で動くパーティで使ってください
  - チャット通知は**パーティで1人だけ**オンにしてください（複数人だと同じ文が人数分流れます）
  - リプレイ再生中はマーカーもチャットも送らず、自分のチャット欄に表示するだけです
