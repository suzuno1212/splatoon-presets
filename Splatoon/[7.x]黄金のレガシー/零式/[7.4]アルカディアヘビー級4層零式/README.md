## スクリプト

### レプリケーション1回目 闇・炎誘導ガイド（近接・タンク）
- ファイル: [M12S_P2_Replication1_DarkBait.cs](M12S_P2_Replication1_DarkBait.cs) → 開いて右上の「Copy raw file」
- 何をするか: 2回目の分身移動で**最外周（斜め）に来た闇分身**を北とみなし、近接・タンクの**闇誘導位置**と**炎誘導位置**を表示します。自分の担当（闇耐性低下IIあり=炎、なし=闇）の位置にはガイド線を引きます。
- 対象: タンク・近接DPS（ジョブから自動判定。ヒーラー・遠隔は表示なし）
- 設定項目:
  - ロール（自動 / タンク / 近接）
  - 炎誘導位置の表示、担当の位置へのガイド線、相方の位置の表示
  - 色
- 攻略法の前提: game8 位置固定式。最外周の闇分身を北として DPS が左・タンクが右
