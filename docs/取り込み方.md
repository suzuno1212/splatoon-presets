# 取り込み方ガイド

## レイアウト

### いちばん楽な方法：Rapid Import（おすすめ）
1. ゲーム内で `/splatoon` → 設定にある **Rapid Import** をオンにする
2. このサイトのレイアウト欄の右上にある **コピーボタン** を押す
3. それだけで自動的に取り込まれます（Splatoon を開いたままにしておく）

### 通常の方法
1. レイアウト欄の右上の **コピーボタン** を押す
2. `/splatoon` → **Layouts** タブ → **Import from clipboard**

### まとめて取り込む
各コンテンツの `layouts.txt` を開いて、右上の **Copy raw file**（コピーアイコン）を押すと、そのコンテンツの全レイアウトをまとめてコピーできます。取り込み手順は上と同じです。

### 更新版を上書きしたいとき
同じ名前のレイアウトがあるとエラーになります。**Ctrl キーを押しながら** Import from clipboard を押すと上書きできます。

## スクリプト

1. スクリプトのリンク（`～.cs`）を開く
2. 画面右上の **Copy raw file**（コピーアイコン）を押す
3. `/splatoon` → **Scripts** タブ → **Install from Clipboard**
4. 一覧に追加されたら、歯車（設定）でロールなどを設定

> スクリプトの更新版を入れるときは、古いものを削除してから入れ直してください。設定は初期化されます。

（ここにボタン位置のスクリーンショットを貼ると親切です：`docs/images/` に置く）
